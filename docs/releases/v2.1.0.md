# Luminesk-CLI 2.1.0

Luminesk 2.1 improves everyday server operation with a more responsive terminal
interface, safely rendered console colors, and a single command to start a
server and open its console. Official installers now use self-contained
application directories for Linux, macOS, and Windows.

## Highlights

### Start and attach in one command

```bash
nesk start --dir ./servers/example --attach
```

Luminesk waits for readiness before opening the full-screen console. If the
server is already running, it attaches without restarting the container.
Use `Ctrl+D` to detach, `Ctrl+C` to stop gracefully, or `Ctrl+K` to kill it.
`--attach` requires an interactive terminal and rejects `--json` and
`--non-interactive` before starting the server.

### Clearer terminal output

- Consistent colors and presentation across commands, prompts, and progress.
- Measured progress for operations that report their size or completion.
- Safe ANSI color rendering in streamed logs and the attached console;
  `NO_COLOR` disables color.
- Faster `--help` and `--version` startup through deferred imports.

### Self-contained application bundles

- Installers use onedir ZIP bundles containing `nesk` and its runtime files.
  Python is not required on the host.
- SHA-256 verification, installation smoke checks, and transactional
  activation protect installs and upgrades.
- Existing installations managed by the one-line installer can be upgraded
  by rerunning it. Extract the complete ZIP when installing manually.
- Platform fixes cover macOS archive handling and Windows installer validation.

### Docker and project links

- Runtime platform selection follows the Docker Engine's OS and architecture.
- Image pulls are explicit and bounded, with progress and useful failures.
- Documentation and installers use [nesk.farin.cc](https://nesk.farin.cc).
  Repository, release, and catalog links use
  [Farin Works](https://github.com/farin-works).

## Install or update

Linux or macOS:

```bash
curl -fsSL https://nesk.farin.cc/sh | sh -s -- --yes
```

Windows AMD64 (x64), PowerShell:

```powershell
irm https://nesk.farin.cc/ps1 | iex
```

For a Python-managed installation, use Python 3.13+:

```bash
uv tool install luminesk-cli
# Upgrade an existing uv installation:
uv tool upgrade luminesk-cli
```

Docker Engine or Docker Desktop is required to run servers. On Windows, use
Linux containers. After upgrading, check `nesk --version`, run `nesk doctor`,
and refresh discovery with `nesk catalog update`.

## Compatibility

Existing 2.x instances and pinned recipe locks remain supported, including
saved official-catalog origins. No manual lockfile or instance-state edits are
required. Keep using the same installation method for CLI upgrades.

Luminesk 1.x instances still require a
[side-by-side migration](https://nesk.farin.cc/docs/migrating-to-2.0).
Back up server data before changing a production installation.

## Release files

- `luminesk-{linux,macos}-{amd64,arm64}.zip`: Linux and macOS bundles.
- `luminesk-windows-amd64.zip`: Windows AMD64 (x64) bundle.
- Python wheel and source distribution.
- `SHA256SUMS`: release-file checksums.
- `luminesk-cli.cdx.json`: runtime dependency SBOM.
- GitHub build provenance attestations for the Python artifacts and bundles.
